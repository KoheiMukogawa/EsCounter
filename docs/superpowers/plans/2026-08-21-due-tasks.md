# 期限つき作業（due tasks）と選考順ソート 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 企業ごとに「期限つき作業」を持てるようにし、企業ツリーを「次にやることが近い順」に並べ替える。

**Architecture:** 企業オブジェクトに `tasks[]` を足し、`nextDue(c)` という1つの純粋関数に
「その企業の次にやること」を集約する。ツリーの並び順・バッジ・2行目はすべてこの関数から
導出する。ES提出期限（既存 `c.deadline`）はデータを作らず、`nextDue()` の中で仮想の1件として
合成する。既存のデータ形式は変えないのでマイグレーションは無い。

**Tech Stack:** バニラ HTML/CSS/JS、`index.html` 単一ファイル。ビルド工程なし、npm 依存なし。

**Spec:** `docs/superpowers/specs/2026-08-21-due-tasks-design.md`

## Global Constraints

- 変更は `index.html` の1ファイルのみ。他のファイルを作らない・触らない。
- **フロントにフレームワーク・npm依存・ビルド工程を足さない**（CLAUDE.md 規約）。
  したがってテストフレームワークは導入しない。純粋関数の検証は
  スクラッチパッド上の使い捨て Node スクリプトで行い、**リポジトリには一切置かない**。
- UI文言・コメントは日本語。
- 既存スタイルに合わせる：セミコロン区切りの詰めた書き方、`const`/`let`、アロー関数。
  新しい抽象化を導入しない。
- `main` は本番（GitHub Pages 配信）。**実装は必ずブランチを切って行う**：
  `git switch -c feat/due-tasks`。push は行わない（ユーザーが実ターミナルから行う）。
- 触ってはいけないもの：`deadlineState()`、Firestore 保存とローカルバックアップ、
  企業操作バー（`renderCompanyBar`）、設問まわり（`buildQItem` と設問のドラッグ並べ替え）。
- 既存データの企業に `tasks` は存在しない。読み出しは必ず `(c.tasks||[])` を使う。
- 手動確認はすべて `python3 -m http.server 8000 --directory .` → http://localhost:8000/ で行う。
- **計画中の行番号は着手前のスナップショットであり、前のタスクの編集でずれる。**
  特に Task 3 が `index.html:936` の手前に約9行を挿入するため、Task 4・Task 5 が引用する
  行番号はその分後ろにずれる。**必ず「置き換え前」のコード断片を検索して位置を特定し、
  行番号は目安としてのみ使うこと。** 断片が見つからない場合は勝手に近いものを書き換えず、

  // ── 企業モーダル: 期限つき作業の行 ──
  function addTaskRow(t){
    const wrap=document.getElementById('taskRows');
    const row=document.createElement('div');
    row.className='task-row';
    row.dataset.tid=(t&&t.id)||'';
    const chk=document.createElement('input');
    chk.type='checkbox';chk.className='task-check';chk.checked=!!(t&&t.done);
    const name=document.createElement('input');
    name.type='text';name.className='modal-input task-name';name.placeholder='例：ウェブテスト';
    name.value=(t&&t.name)||'';
    const due=document.createElement('input');
    due.type='date';due.className='modal-input task-due';due.value=(t&&t.due)||'';
    const del=document.createElement('span');
    del.className='task-del';del.textContent='×';
    del.addEventListener('click',()=>row.remove());
    row.append(chk,name,due,del);
    wrap.appendChild(row);
  }
  function renderTaskRows(tasks){
    const wrap=document.getElementById('taskRows');
    wrap.innerHTML='';
    (tasks||[]).forEach(t=>addTaskRow(t));
  }
  function collectTaskRows(){
    return [...document.querySelectorAll('#taskRows .task-row')].map(row=>({
      id:row.dataset.tid||genId(),
      name:row.querySelector('.task-name').value.trim(),
      due:row.querySelector('.task-due').value,
      done:row.querySelector('.task-check').checked
    })).filter(t=>t.name&&t.due);
  }
